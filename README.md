# RDP Console

Невеликий застосунок для Windows — швидкий пошук і запуск файлів підключень
`*.rdp`, які зберігаються в одній папці (разом з підпапками по клієнтах).
Підключення — лише через стандартний Windows RDP-клієнт (`mstsc.exe`).

Ідея та стиль збірки — за прикладом
[ShadowSessionTool](https://github.com/Pro100NeFarT/ShadowSessionTool):
один файл `.cs`, компільований вбудованим у Windows компілятором `csc.exe`
(з .NET Framework), без потреби встановлювати .NET SDK чи Visual Studio.

## Можливості

- Рекурсивне сканування вказаної папки на файли `*.rdp`.
- **Ієрархічний перегляд** (за замовчуванням) — справжнє дерево папок, як у
  провіднику: підпапки розгортаються/згортаються, на кожному рівні спершу
  йдуть папки (за абеткою), потім файли цього рівня. Кнопка "☰ Список" /
  "🌲 Ієрархія" вгорі перемикає на плаский список (згрупований по папках,
  без вкладеності) і назад; вибір запам'ятовується між запусками.
- Миттєвий пошук — фільтрація за назвою підключення або назвою папки; поки
  триває пошук, завжди показується плаский список збігів, незалежно від
  вибраного режиму перегляду.
- Подвійний клік / Enter — підключення через `mstsc.exe`.
- Збереження пароля для швидкої вставки (ПКМ → "Зберегти пароль..."):
  пароль шифрується через Windows DPAPI (прив'язка до поточного облікового
  запису Windows на цій машині — так само зберігають майстер-паролі інші
  менеджери підключень) і зберігається в налаштуваннях. При підключенні
  (подвійний клік / Enter / "Підключитися") пароль автоматично вставляється в
  `mstsc` -- діалог пароля Windows найчастіше взагалі не з'явиться (див.
  "Автозаповнення пароля" нижче); про всяк випадок пароль додатково
  копіюється в буфер обміну, тож Ctrl+V теж спрацює. Пункт "Копіювати
  пароль" — скопіювати повторно в будь-який момент,
  "Видалити пароль" — прибрати збережений пароль. У списку підключень
  колонка "Пароль" показує ✓ для тих, де збережено власний пароль, і • —
  де власного немає, але спрацює пароль за замовчуванням.
- Пароль за замовчуванням (Налаштування → "Пароль за замовчуванням..."):
  якщо для конкретного підключення власний пароль не збережено, при
  підключенні в буфер обміну копіюється саме цей пароль. Зручно, коли на
  більшості серверів однаковий пароль, а виняткам можна задати власний
  окремо (він завжди має пріоритет над паролем за замовчуванням).
- Контекстне меню (ПКМ): підключення, керування паролем, "Показати у
  провіднику", "Копіювати шлях", "Редагувати файл (Блокнот)".
- F5 — оновити список (пересканувати папку).
- **"Завершити програму"** — кнопка зліва від "Налаштування" в головному вікні
  (і в вікні швидкого пошуку з трея) — єдиний спосіб дійсно закрити застосунок;
  звичайне закриття вікна чи Х лише ховає його в трей.
- **Перевірка оновлень із GitHub** (стиль — за зразком
  [ShadowSessionTool](https://github.com/Pro100NeFarT/ShadowSessionTool)) —
  зліва вгорі: намальована іконка-ланцюжок (відкриває репозиторій у браузері)
  і підкреслений номер версії, що виглядає як посилання. Тиха перевірка
  відбувається при кожному запуску — якщо є новіша версія, номер підсвічується
  помаранчевим (v1.1.1 ↑), без спливаючого вікна. Клік по номеру версії —
  одразу пропонує оновитися (завантажує готовий `.exe` з останнього релізу й
  перезапускає застосунок автоматично); якщо оновлень немає — повідомляє, що
  версія вже остання.
- **Іконка в треї ("віджет")** — застосунок завжди доступний через іконку в
  треї (панель задач біля годинника), навіть коли головне вікно закрите.
  Закриття вікна (хрестик) чи згортання ховає його в трей, а не завершує
  роботу — застосунок продовжує працювати у фоні. Клік лівою кнопкою на
  іконці — відкрити вікно знову. Клік правою — одразу відкриває маленьке
  віконце швидкого пошуку біля курсора (без проміжного меню): почніть
  вводити назву, Enter підключає виділений результат, Esc закриває. У цьому
  ж вікні — кнопка "Завершити програму".
- **Один екземпляр**: повторний запуск `RdpConsole.exe`, коли застосунок уже
  працює, не створює другу копію (і другу іконку в треї) — натомість просто
  показує вікно вже запущеного екземпляра.
- **Глобальна гаряча клавіша** (за замовчуванням Ctrl+Alt+R) — відкриває те
  саме вікно швидкого пошуку з будь-якого місця в Windows (навіть коли
  застосунок згорнутий у трей і жодне його вікно не видно), без потреби
  спершу клікати по іконці. Комбінацію можна змінити в Налаштуваннях:
  клацнути в поле й натиснути бажані клавіші (потрібен хоча б один
  Ctrl/Alt/Shift), або взагалі вимкнути кнопкою "Вимкнути". Якщо комбінацію
  вже зайняла інша програма — при запуску або зміні прийде повідомлення з
  кодом помилки Windows (сама програма далі працює нормально).
- **Автозаповнення пароля** — окрім копіювання в буфер обміну, застосунок
  дописує пароль прямо у тимчасову копію `.rdp`-файлу в тому самому форматі
  (`password 51:b:...`), яким сам `mstsc.exe` зберігає введені облікові дані.
  Якщо у файлі вже є `username:s:...` (майже завжди є), `mstsc` підключається
  одразу, без діалогу вводу пароля. Тимчасовий файл з паролем автоматично
  видаляється через ~20 секунд після запуску `mstsc` (він потрібен лише в
  момент старту).
- Налаштування (лише папка з `.rdp`) зберігаються в
  `%AppData%\RdpConsole\settings.json` і не втрачаються між запусками.
- Перед кожним підключенням застосунок створює тимчасову копію `.rdp`-файлу
  (у `%TEMP%\RdpConsole\`), у якій примусово вмикає дозволи "Буфер обміну",
  "Принтери", "Смарт-карти" й "WebAuthn". Оригінальний файл не змінюється.
  Тимчасова копія, на відміну від оригіналу (який міг отримати позначку
  "з Інтернету" від хмарного синхронізатора), її не має -- тому попередження
  Windows "Невідомий видавець" для неї, як правило, не з'являється.
- Власна іконка (`RdpConsole.ico`, генерується `GenerateIcon.ps1`).

## Встановлення / запуск

Встановлення не потрібне — один файл `RdpConsole.exe`, без залежностей, крім
.NET Framework 4 (вже вбудований у Windows 10/11 та Windows Server 2012 R2+).

При першому запуску застосунок запитає папку з файлами `.rdp`
(наприклад, `D:\GoogleDrive\_WORK\RDP`).

## Збірка з вихідного коду

```powershell
.\build.ps1
```

Скрипт викликає вбудований компілятор:

```powershell
$csc = "$env:WINDIR\Microsoft.NET\Framework64\v4.0.30319\csc.exe"
& $csc /target:winexe /platform:anycpu /codepage:65001 `
    /out:RdpConsole.exe `
    /win32manifest:app.manifest `
    /reference:System.dll,System.Core.dll,System.Windows.Forms.dll,System.Drawing.dll,System.Runtime.Serialization.dll,System.Security.dll `
    RdpConsole.cs
```

## Нотатки

- Права адміністратора не потрібні (`asInvoker` у `app.manifest`).
- Збережені паролі захищені Windows DPAPI (`CurrentUser` scope) — розшифрувати
  їх можна лише під тим самим обліковим записом Windows на тій самій машині.
  Якщо потрібно перенести підключення з паролями на інший комп'ютер або під
  інший обліковий запис, паролі доведеться ввести заново.
